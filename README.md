# Ссылки → Finder — плагин Agents Hub

Клик по ссылке на файл в чате сессии открывает папку с выделенным файлом: на Mac — Finder, на Windows — Проводник.
Работает на компьютере, где стоит хаб; с телефона и по ⌘/Ctrl-клику ссылка открывается, как раньше, в «Файлах».

Нужен хаб с `/api/reveal` на странице (POST `{path, cwd}`); без него клик открывает «Файлы».

Поставить: «Настройки» → «Плагины» → «Можно поставить» → reveal-links.
